# OpenIG831T v0.1.0 — Research Preview

**EXPERIMENTAL — END-TO-END 5G REPLACEMENT NOT YET DEMONSTRATED**

## Confirmed original-device findings

**CONFIRMED_TARGET_DEVICE:** measured IG831T USB composition; Fibocom NL668T-GL reported identity; MI_02 AT and MI_04 QMI control; initialization and 29-service discovery; WDA RAW_IP with aggregation disabled. These findings concern the original dongle, not a replacement candidate.

## Included software and documentation

**SOURCE_SUPPORTED:** original descriptor/configfs/FunctionFS, AT, QMI/session/CDC queue, bounded libusb/laboratory-coordinator and offline RAW_IP/QMAP components; explicit execution gates; tests and publication tooling; separately licensed experimental FunctionFS patches. The release also includes original English documentation, corrected static host-path summaries, sanitized metadata and public references.

## Validation

The final curated-tree test and scan results belong to the publication validation artifacts for this release. Pre-curation private development totals are not claimed here as public test results. CI and sanitizer checks concern software boundaries; they do not prove physical compatibility. Record all skips and the exact source/archive hashes when reproducing.

## Physical work not completed

**UNKNOWN:** exact candidate firmware compatibility, physical 9-IN/5-OUT UDC allocation, full kernel build/boot, FunctionFS gadget operation, DJI host acceptance, active host path, physical data frames and end-to-end 5G. Direct replacement and bridge necessity remain unestablished; final verdict is null.

Still required: an identified candidate/carrier/power/RF setup, a validated USB-device/USB-host platform, and an exact authorized host context. No purchase recommendation or safe wiring guarantee is made.

## Distribution boundaries

Only curated original source, documentation, permitted patches, sanitized summaries, synthetic vectors and checksums are eligible release assets. Proprietary packages, firmware, complete manuals, raw personal captures and private history are excluded. No firmware flashing, identity rewriting of IMEI/SIM, cryptographic bypass or automatic active data workflow is provided.

## Curated publication validation

**SOURCE_SUPPORTED:** the curated suite ran 241 tests with zero failures, errors or skips when the optional hash-verified source cache was available. Three default CLI smoke checks passed. A fresh clone intentionally skips the two optional source/header checks unless that cache is explicitly fetched. The two C harnesses passed strict compilation and ASan/UBSan (74 and 1,268 assertions). These results demonstrate software behavior only, not physical hardware compatibility. Exact-commit GitHub Actions results are checked before publication.
