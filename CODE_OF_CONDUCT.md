# Code of Conduct

OpenIG831T welcomes respectful, evidence-led collaboration. Discuss results and limitations without personal attacks. Ask clear questions, acknowledge uncertainty and correct errors openly.

Harassment, discrimination, threats, doxxing, credential sharing and pressure to test someone else's hardware are unacceptable. Do not post another person's private information or proprietary material. Respect differing technical experience and accessibility needs.

Maintainers may edit or remove harmful content, limit participation or close discussions to protect participants and the project. Enforcement should be proportionate and explained without republishing sensitive details.

Report concerns through an available private repository channel. If no private channel is available, request one without identifying affected people or posting confidential evidence in public. No personal contact address is fabricated by this release.

This is an original project policy, not a claim of affiliation with an external conduct program.
